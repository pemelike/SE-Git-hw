# SE-Git-hw

## Project Description

This repository was created for Assignment #1 in CINS 5318 Software Engineering. It demonstrates the use of Git and GitHub for version control and collaboration.

## Project Files

- hello.py: Displays a Hello World greeting.
- apple.py: Displays “I eat apple.”
- README.md: Provides information about the project.

## How to Run the Programs

Run the Hello World program:

    python hello.py

Run the apple program:

    python apple.py

## Branches

- main: Contains the completed project.
- feature-1: Used to create the apple program.
- conflict-demo: Used to demonstrate a merge conflict.

## Pull Requests

A pull request was created to merge feature-1 into main. A classmate reviewed and approved the pull request before it was merged.

## Merge Conflict

A merge conflict was created by changing the same line in hello.py on the main and conflict-demo branches. The conflict was resolved by removing the conflict markers and keeping a final combined greeting.

## GitHub Issues

Two issues were created. One was assigned to me to improve the README, and the other was assigned to a classmate to test the programs. Both issues were completed and closed.
